# Personal_task_OZI

## Опис проєкту

Цей проєкт демонструє застосування криптографічного цифрового підпису зображень у поєднанні з LSB-стеганографією — технікою, яка дозволяє приховати підпис всередині самого зображення. Мета — створити цілісну і візуальну однакову картинку, в порівнянні з орігальним зображенням, яка буде в собі мати схований підпис.

## Принцип роботи

### Генерація ключів RSA

Для забезпечення надійного цифрового підпису використовується пара криптографічних ключів RSA довжиною 4096 біт. Така довжина забезпечує сучасний рівень стійкості до криптоаналізу та відповідає загальноприйнятим стандартам безпеки.

Ключі поділяються на:

- Приватний ключ (private_key.pem) — застосовується виключно для створення підпису. Його необхідно зберігати у надійному та недоступному для сторонніх місці, оскільки компрометація цього ключа означає втрату довіри до підписів.

- Публічний ключ (public_key.pem) — використовується для верифікації підпису. Цей ключ може бути відкрито розповсюджений разом із підписаними зображеннями.

Для генерації ключів використовувався файл keys.py та перед тим встановлені бібліотеки які зазначені в requirements.txt.

### Підписування (sign_image.py)

1) Зчитується приватний ключ (private_key.pem).
2) Хешується вміст зображення за допомогою SHA256.
3) Хеш підписується приватним ключем.
4) Отриманий підпис приховується в зображенні за допомогою LSB.
5) Зберігається нове зображення з підписом (наприклад, signed_bmp.png).

### Перевірка підпису (verify_signature.py)
1) Зчитується публічний ключ (public_key.pem).
2) Витягується прихований підпис із зображення.
3) Повторно обчислюється SHA256-хеш для оригінального зображення.
4) Підпис перевіряється за допомогою публічного ключа.
5) Виводиться результат: підпис дійсний / недійсний.

## Інноваційність рішення

- Підпис генерується за допомогою асиметричної криптографії (RSA + SHA256).
- Підпис не зберігається окремо, а приховується безпосередньо у пікселях зображення за допомогою LSB-стеганографії що у свою чергу забезпечує безшумне приховування  .
- Таким чином, ззовні зображення виглядає ідентично до вхідного, а підпис знайти не просто без знання специфіки реалізації.
- Автоматична перевірка підпису без зовнішніх даних.
